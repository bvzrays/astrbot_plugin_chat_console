# 聊天控制台

在 AstrBot WebUI 中查看和管理机器人运行期间收到的群聊消息。插件按平台和会话整理消息，提供未读提醒、@机器人消息定位、会话置顶、备注与支持主动发送的适配器消息发送。

## 功能

- 按适配器浏览已收到消息的群聊，并增量同步新消息。
- 打开会话时标记已读；保留进入会话时的未读快照，支持跳转到未读消息和 @机器人的消息。
- 发送文本、图片和图文消息（取决于适配器是否支持主动发送及平台权限）。
- 置顶会话、修改本地备注、查看主动回复配置状态。
- 深色模式默认开启；可在控制台右上角切换。WebUI 插件配置中的“深色模式”控制首次使用的默认主题；网页中的手动选择会记在当前浏览器。
- 使用 SQLite 保存聊天记录，并在首次启动时自动迁移旧版 `messages.json`。

## 安装

将插件目录放入 AstrBot 的 `data/plugins/`，或在 AstrBot WebUI 的插件管理中安装，然后启用插件并打开插件详情页中的“聊天控制台”。插件要求 AstrBot 4.24.2 或更新版本，不需要额外安装 Python 依赖。

## 使用

选择左侧适配器和群聊即可查看消息。进入群聊后会立即向插件保存的本地已读状态；右上方的未读和“有人@我”按钮可以定位相应消息。右键群聊可置顶、修改备注或标记已读。

发送消息前，插件会检查适配器是否声明支持主动发送；平台侧的授权、会话标识和策略也可能限制发送。没有主动发送能力的适配器仍可用于查看已记录消息。

## 配置

在 **WebUI → 插件管理 → 聊天控制台 → 配置** 中启用或关闭“默认使用深色模式”。页面右上方的主题按钮可在深色与浅色外观间即时切换；该手动选择优先于默认配置，并保存在当前浏览器。

## 数据与隐私

插件只记录启用后 AstrBot 实际收到的消息，不会从平台下载此前的完整聊天历史。聊天记录保存在 AstrBot 的 `data/plugin_data/astrbot_plugin_chat_console/chat_console.db` SQLite 数据库中，并保留最近 5000 条。首次启用新版时会把旧 `messages.json` 导入 SQLite，成功后将原文件改名为 `messages.json.migrated` 以便回退。数据库、迁移备份和群备注/置顶设置均保留在运行环境中，不应上传到代码仓库。

## 兼容性

界面按多适配器会话模型设计。目前仅在 QQ 官方机器人和 NapCat 上进行过测试；不同适配器的群标识、主动发送能力、@消息结构和媒体链接可能不同。
